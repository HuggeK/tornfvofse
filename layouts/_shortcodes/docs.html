Filstorleken räknas ut vid bygget – bra att veta innan man laddar ner 20 MB på 4G. Fält per rad i yaml: title – visningsnamn (obligatoriskt) url – lokal sökväg eller extern länk; utelämnas för rena textrader note – liten rad under titeln, får innehålla markdown-länkar badge – text i märket; annars filtyp/Länk/Info automatiskt --------------------------------------------------------------------------- */}} {{ $group := .Get "group" }} {{ $data := index hugo.Data.documents $group }} {{ if not $data }} {{ errorf "docs: gruppen %q saknas i data/documents.yaml (anropad från %s)" $group .Position }} {{ end }}
